# QingProcess 前端应用 (AI Studio)

全源流程资产管理平台前端工程，由 Google AI Studio 开发构建。

## 技术栈
- **框架**: React 19 + TypeScript
- **样式**: Tailwind CSS v4
- **图标**: Lucide React
- **图表/拓扑**: D3.js + Drawio Embedded
- **构建工具**: Vite 8

## 核心功能模块
- **系统首页 / 工作台**: 流程待办、我的负责流程、我参与的流程与企业动态
- **流程资产 / 流程概览**: 流程资产发布架构树、业务集成视图、流程卡片、版本历史、穿透下钻
- **流程建设 / 流程设计**: Drawio 流程设计画板、在线保存与预览、标准卡片资料维护、制度文件与风险合规关联
- **权责管控 / 权责审核**: DOA分权手册、权责审核与流转
- **组织架构**: 企业组织架构树、跨部门多选选人（负责部门、负责人、协作者、适用范围）

## 开发与构建
```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 编译打包生产版本
npm run build
```
