# 制度文件自定义模板

入口：风控合规 → 制度文件库 → 自定义模板。新增、编辑制度的弹窗也有“管理自定义模板”。

模板可设置名称、红头标题、发文字号、签发人、密级、正文标题、完整正文、落款、水印、红头颜色与字号、正文字号。正文采用纯文本分章、条款和换行排版，不执行HTML或脚本。

支持变量：{{companyName}}、{{docNo}}、{{referenceNo}}、{{title}}、{{versionNo}}、{{ownerName}}、{{publishTime}}。应用时公司名称取服务器公司资料；文号优先使用文件填写的发文红头文号，未填写时使用制度编号。

新建模板或修改模板后点击保存。修改同一模板使用revision检查，其他人先保存时会提示重新打开，不覆盖别人的修改。

新增/编辑制度：先填写文件名称、编号，再选择模板。应用会替换当前未保存正文；应用后可单独修改红头和正文，也可从空白正文编写。保存制度进入既有审核流程，正文JSON与制度条目同事务持久化。保存时记录内容快照和模板版本，公共模板后续更新不修改已有制度。

预览展示真实模板正文，或已上传的PDF原文件；没有原文件或模板正文时明确提示。模板正文可导出UTF-8 HTML，或打印并由浏览器保存PDF；其他原文件下载原始字节，不再生成假DOCX/PDF文件。

模板存储于dictBundle.documentTemplates，制度正文存储于sysDoc条目的documentContent，复用app_settings事务持久化，不需要新增迁移。读接口供已登录成员访问，写接口沿用editor/admin权限；公开只读视图不显示编辑入口。
